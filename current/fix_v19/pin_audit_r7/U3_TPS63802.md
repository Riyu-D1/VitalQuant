## Reference design / sequencing / passives
- L1 0.47 µH = DS recommended; FB ratio sets 3.30 V exactly per §8.2.
- Output decap: local C38 100 n @1.6 mm closes the HF SW loop; +3V3 is a plane on layers F.Cu + L10, so C45 22 µ + C85 47 µ board bulk reach VOUT with plane inductance. DS "COUT close" guidance is partially met — **documented deviation, justified**: no free 0402+ slot inside U3's crowded courtyard ring, and the converter is stable (validated). Alternative considered — relocating C45 — rejected (would strip board-level 3V3 bulk).
- PG left unconnected: DS permits (open-drain, unused flag).
- Input side fully compliant: C46+C44 within 2 mm.

## Disagreements vs R5 audit
R5 did not flag the Cout proximity. This round documents it as an accepted deviation (plane-backed distribution, no feasible relocation site) rather than a defect; measured values added.
