# U22 — MAX86141ENP+ per-pin audit (Round 5, datasheet verify/datasheets/max86141.pdf)

Abs-max (p.4): VDD_ANA/VDD_DIG −0.3..+2.2V; **SCLK, SDO, SDI, CSB, INT to GND_ANA −0.3..+6.0V** — confirms digital pins are 6V-tolerant.
