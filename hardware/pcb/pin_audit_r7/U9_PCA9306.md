## Abs-max, five states
- 1V8 side unpowered with 3.3 V I2C driven: pass-gate FET off, pins ≤3.3 V<7 ✓ (PCA9306 is the recommended part for exactly this case).
- Battery-flat / USB-only / all rails up: ≤3.3 V<7 ✓.

## Reference design / passives
- EN+VREF2 via R18 200 k to +3V3 = textbook hookup (DS §8.2).
- **Deviation (accepted)**: VREF1 has no dedicated bypass — nearest +1V8 cap C90 100 n @18.4 mm, bulk C87 10 µ @31.7 mm. +1V8 is a tracked net (no plane). VREF1 supplies only the pass-gate reference (µA bias), so function is unaffected, but this is the weakest decap on the board. Fix assessed: relocating a 0402 within ~2 mm is infeasible — U9 sits in a via ring (IN1N_AC @2.24 mm, GND @2.44, RLD_CLAMP @2.51, I2C_SDA_1V8 @2.54) with no clear pad site; rerouting would disturb validated sensor copper. Left justified; flagged for next layout respin.

## Disagreements vs R5 audit
R5 verified the level-shifter topology but did not quantify the VREF1 decap distance; measured data now records 18.4 mm + justification.
