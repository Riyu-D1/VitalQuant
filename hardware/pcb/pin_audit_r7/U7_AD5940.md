## Abs-max, five states
- AVDD/IOVDD ≤3.3 V<3.6 ✓; electrode pins see only sensor-side nodes through series C/R ✓; USB-only unpowered: SPI side from U1 = 3.3 V-domain but IOVDD=0 → SPI pins are NOT rated above IOVDD — however U1's SPI pins tri-state/hi-Z at boot and CS idle; residual injection through ESD diodes ≤ pin limits; noted as accepted (same class as R5 finding).
- Skin-fault: electrode pins are the patient interface — protected by series 470 n + the AFE's own ESD; electrode rule areas present on PCB (verified in layout fixes).
